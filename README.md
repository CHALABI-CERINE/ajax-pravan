# ⚙️ TP8 – SPA, AJAX & Web Services avec Flask

## 🎯 Objectif du TP
L’objectif de ce TP est de vous familiariser avec les **Single Page Applications (SPA)**, **AJAX** et les **Web Services**.  
Vous allez mettre en pratique ces notions à travers **6 exercices progressifs**, permettant de comprendre le fonctionnement des échanges asynchrones entre le client et le serveur.

---

## 📘 Ressources fournies
- Le fichier **`TP8_AJAX.pdf`** vous guide *étape par étape* dans la réalisation de ce TP.
- Tous les scripts Python, JavaScript, HTML et CSS doivent être **clairement commentés**, en indiquant le **numéro de slide du cours** si nécessaire.  
  > Exemple :
